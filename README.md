# 🧙‍♂️ SpellType Survivor: Thai Mystic Keyboard (จอมเวทแป้นพิมพ์เอาชีวิตรอด)

เกมฝึกพิมพ์สัมผัสภาษาไทยแนว **Typing Roguelite Survivor** สไตล์ย้อนยุค (Retro Pixel Art) พัฒนาด้วย **HTML5 Canvas + TypeScript + Web Audio API**

---

## 🎮 วิธีการเล่น (How to Play)

1. **การควบคุมการพิมพ์:**
   - ผู้เล่นวาง 10 นิ้วบน **แป้นเหย้า (Home Row: ฟ ห ก ด ่ า ส ว)** โดยไม่ต้องละมือไปใช้เมาส์
   - เมื่อมอนสเตอร์เกิด จะมีคำศัพท์ภาษาไทยลอยเหนือหัว
   - **Auto-Lock:** พิมพ์ตัวอักษรแรกให้ตรงกับคำ ระบบจะล็อกเป้าหมายตัวที่ใกล้เราที่สุดทันที
   - ตัวอักษรที่พิมพ์ถูกจะเรืองแสงสีฟ้า ตัวอักษรปัจจุบันจะกระพริบสีเหลือง และมีคำแนะนำนิ้วมือที่ต้องกดแสดงบนแป้นพิมพ์เสมือนด้านล่าง
2. **Smart Dual Mapping:**
   - สามารถเล่นได้ทันทีแม้ว่าระบบปฏิบัติการจะตั้งเป็นคีย์บอร์ดไทย (TH) หรือภาษาอังกฤษ (EN) โดยไม่ต้องคอยสลับภาษา
3. **Spacebar Flash Dash (เคาะเวทฉุกเฉิน):**
   - เมื่อพิมพ์สำเร็จ หลอดเกจ Dash จะเพิ่มขึ้นเรื่อยๆ
   - เมื่อเกจเต็ม กด **Spacebar** เพื่อระเบิดคลื่นกระแทกผลักมอนสเตอร์ทุกตัวในระยะถอยหลังทันที
4. **ระบบ Roguelite Perks (เลเวลอัป):**
   - **💥 วรรณยุกต์ระเบิด:** เมื่อพิมพ์วรรณยุกต์ (่, ้) จะระเบิด Splash ดาเมจใส่มอนสเตอร์รอบข้าง
   - **⚡ สระสายฟ้าชิ่ง:** เมื่อพิมพ์สระ (า, ะ, ั, ี) ปล่อยสายฟ้าชิ่งใส่มอนสเตอร์ข้างเคียง
   - **🔥 เร่งจังหวะมหาเวท:** เมื่อพิมพ์เร็วเกิน 35 WPM พลังโจมตีและ EXP จะเพิ่มขึ้นอย่างมหาศาล
   - **🛡️ คลื่นกระแทกมหาศาล:** Dash ชาร์จเร็วขึ้น 40% และผลักศัตรูไกลขึ้นสองเท่า
   - **💚 ฟื้นฟูพลังเวท:** พิมพ์สำเร็จครบทุก 4 คำ ฟื้นเลือด 12 HP

## 📱 การเล่นบนโทรศัพท์มือถือและแท็บเล็ต (Mobile & Tablet)

- **เชื่อมต่อผ่านเครือข่าย Wi-Fi เดียวกัน:**  
  เปิดเบราว์เซอร์บนมือถือหรือแท็บเล็ตแล้วพิมพ์ลิงก์:  
  👉 **`http://10.12.129.163:5173/`**
- **แป้นพิมพ์สัมผัสบนหน้าจอ (Touch Keyboard):**  
  สามารถใช้นิ้วแตะปุ่มบนหน้าจอโดยตรงได้ทันที มีแสงเรืองและเอฟเฟกต์ตอบสนองฉับไว ปรับขนาดอัตโนมัติตามขนาดจอ
- **Spacebar Dash:** แตะที่แถบ `SPACEBAR` ด้านล่างจอเพื่อระเบิดคลื่นผลักศัตรู
- **คำแนะนำ:** แนะนำให้หมุนหน้าจอเป็น **แนวนอน (Landscape)** เพื่อให้ปุ่มมีขนาดใหญ่ กดง่าย และมองเห็นสนามรบได้กว้างขวางที่สุด

## 💻 วิธีการรันโครงการ (Running Locally)

```bash
# ติดตั้ง dependencies
npm install

# รัน Development Server
npm run dev

# ทดสอบ Build สำหรับ Production
npm run build
```

เปิดเบราว์เซอร์ไปที่: `http://127.0.0.1:5173/`
